# Start Here

Jika Anda menyerahkan ZIP ini ke coding agent, mulai dengan prompt:

```text
Pelajari AGENTS.md dan semua dokumen di folder docs.

Tujuan kita adalah membangun aplikasi Laporan Proyek secara bertahap.

Untuk sekarang kerjakan HANYA Milestone 0 pada docs/ROADMAP.md:
- rapikan npm workspaces
- siapkan apps/web dan apps/api
- siapkan packages/calc, shared, config
- siapkan script lint/typecheck/test/build
- pastikan Docker Compose MySQL dapat digunakan
- jangan implementasikan business feature dulu

Gunakan npm saja.
Jangan gunakan pnpm/yarn.
Jangan ubah business rules dari docs/PRD.md.
Setelah selesai, jalankan checks yang tersedia dan jelaskan perubahan.
```

Lalu lanjut milestone satu per satu.
